# Security Policy

## Reporting a vulnerability

**Please do not open a public issue.** A report in the issue tracker is visible
to everyone, including to whoever might use the flaw before it is fixed.

Two private ways, either is fine:

- **GitHub** — the *Report a vulnerability* button on the
  [Security tab](https://github.com/kdjfs-design/kirby-login-legal-links/security).
  This keeps the whole exchange private until the report is published.
- **Email** — kontakt@janstieler.de

What helps in a report:

- the plugin version, the Kirby version and the PHP version
- steps to reproduce, and what an attacker gains from it

Please give some time to fix the issue before making it public. This is a plugin
maintained alongside client work, so an answer may take a few working days —
you will get one, and you will be told when a fix is out. There is no bug
bounty.

## Supported versions

The latest release. There are no maintained older lines, and older versions do
not receive fixes.
